# 行政区域策划

目录：`docs/country/行政区域/`。先读 `README.md`。特征是源，表格是产物。

## 改哪一层

1. **调国家差异、兵力比例、明星聚集地**：改 `特征/国家特征.json` 或 `特征/兵役与国势.json`，然后运行 `工具/generate_regions.py`。不要手改 `产出/十国行政区划.xlsx`。
2. **调各级指标窗口（上下限）**：改 `工具/build_rulebook.py` 里的 `rules`，运行它，写出 `产出/行政区域规则表.xlsx`。窗口不反向改十国树。
3. **手改某一座城**：用 `工具/行政区域生成器.html` 的行政树，或改它导出的 JSON / `明细`。不要为此重跑 `generate()`，随机数会整国重刷。正式差异表仍以 Python 产物为准。
4. **改工具**：保持级别下标 `0村 1乡 2县 3郡 4京畿 5要塞`，九项指标顺序，以及导出表名。生成器导出是 `总览/明细/规则`，规则工作簿是 `行政区域规则/兵种强度/城市数据/说明`。

## 必须一起守住的口径

- 表内兵力 = 人口 × 兵役常备。国势加征随世界变化，不写入常备。常备：息民 5%、守成 8%、经武 10%、整军 11%、穷兵 12%。中原为经武，且是十国常备比例的中位数。
- 人口从多到少：南方、中原、东方、北方、西方；南方约为西方的 2 倍。面积从多到少：西方、北方、中原、东方、南方。
- 人口 = 面积 × `basePersonsPerKm2` × `popDensity`。面积 = `totalAreaKm2` × 领土权重 / 权重合计。权重合计保持 438。
- 特长：南方经济与粮食；东方政治与制造；中原科技、粮食与文化；西方城防、兵员比例与粮食；北方英雄、城防、兵员与畜牧。四方综合战力接近，中原稍高。
- `unitQ`（B1–B12）只描述兵种强度，不参与分地。B3–B12 合计四方为 35，中原为 38。
- 明星倍率不超过 `metricPeakMax`（8），面积倍率不超过 `areaPeakMax`（3）。中原的 `metricPeak` 保持 4。
- 国名与五方十国方案一致：G2 苍羽、G8 烈庭。方位策划名：南方、中原、东方、北方、西方。

## 生成

```bash
python3 docs/country/行政区域/工具/generate_regions.py
python3 docs/country/行政区域/工具/build_rulebook.py
```

依赖 `openpyxl`。`generate_regions.py` 失败时不要留下未通过自检的表。自检包括常备占比、常备中位数、人口和面积的方位顺序、南方/西方人口比、各项特长谁最高、四方综合与中原综合。

浏览器生成器里的 `COUNTRIES` 必须和 `国家特征.json` 的权重、常备、密度、贫富和制造等系数一致。改 json 后同步这组字面量。生成器里的兵力只用 `standing`，不要再加国势。
