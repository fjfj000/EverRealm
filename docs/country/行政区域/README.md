# 行政区域

十国区划的特征和生成工具。改数字先改 `特征/`，再运行脚本，不要手改导出的表格。

## 目录

| 路径 | 内容 |
| --- | --- |
| `特征/兵役与国势.json` | 五档兵役、五档国势，以及各自占人口的比例 |
| `特征/国家特征.json` | 十国方位、领土权重、人口密度、贫富、明星聚集地 |
| `工具/generate_regions.py` | 按特征生成 `产出/十国行政区划.xlsx` |
| `工具/build_rulebook.py` | 生成规则窗口工作簿 `产出/行政区域规则表.xlsx` |
| `工具/行政区域生成器.html` | 浏览器里查看和手改。国级兵力和领土权重与特征文件一致 |
| `产出/` | 脚本写出的表格 |

## 口径

表里的兵力是常备：人口 × 兵役。国势会随世界发展变化，加征不写进常备人数。

兵役：息民 5%、守成 8%、经武 10%、整军 11%、穷兵 12%。中原是经武，也是十国常备比例的中位数。

国势加征：生聚 0%、务本 2%、整备 4%、戒严 6%、征伐 8%。

人口从多到少：南方、中原、东方、北方、西方。南方约为西方的 2 倍。面积从多到少：西方、北方、中原、东方、南方。面积按领土权重分 960 万 km²，权重合计 438。

| 方位 | 国家 | 要点 |
| --- | --- | --- |
| 南方 | 百岭、炽焰 | 经济最发达，粮食最多，常备轻 |
| 中原 | 天衡、昭武 | 常备约 10%。科技、粮食、文化强，综合稍高 |
| 东方 | 青岚、苍羽 | 政治最高，制造业最发达 |
| 北方 | 朔风、烈庭 | 英雄最多，城防强，兵多，畜牧业发达 |
| 西方 | 玄戈、昆岳 | 土地最广、人口最少。城防最强，兵多，粮食较多 |

四方综合战力接近，中原稍高，对应兵种强度合计 35 与 38。明星聚集地仍把特色指标拉开，不超过 8 倍；中原停在 4 倍。

## 重算

```bash
python3 docs/country/行政区域/工具/generate_regions.py
python3 docs/country/行政区域/工具/build_rulebook.py
```

需要 `openpyxl`。生成脚本会检查人口和面积的方位顺序、南方约为西方人口的 2 倍、常备中位数、各项特长，以及四方综合接近、中原稍高。
