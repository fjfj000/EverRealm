# 评审文档

方案比较、选型结论和评审记录放在这里。规格和设定仍留在原目录，例如 `docs/世界架构/`、`docs/country/`。

## 存放规则

一类评审一个子目录，目录名用类别，文件名用这次评审的题目。

```text
docs/评审文档/
  状态枚举/
    枚举状态选型.md
  <类别>/
    <题目>.md
```

新的同类文档按这个结构新增，不改已有类别的目录名。同一类别的后续评审放进同一个子目录。
