# 角色属性与行动

玩家从默默无闻到争霸的属性、技能和行动。这是初稿，门槛里的待调数字可以在编辑器里改。

阶段只用来归类。一个行动能不能做，看它自己的动作限制，以及「总体约束」。前期行动是本人亲自做，占城之后改成批示和委任。

## 目录

| 路径 | 内容 |
| --- | --- |
| `输入/属性行动.json` | 唯一的编辑源。说明、经验曲线和各张表都在这里 |
| `工具/属性行动编辑器.html` | 在浏览器里改表 |
| `工具/serve.py` | 本机打开编辑器。保存会写回 JSON，并更新 xlsx |
| `工具/build_workbook.py` | 只根据 JSON 重新导出 xlsx |
| `产出/属性行动.xlsx` | 给策划看的导表。不要手改，下次生成会盖掉 |

表的顺序和列都写在 JSON 里。编辑器里新增的行、列、表，保存后会一起进 xlsx。

## 怎么改

```bash
python3 docs/角色/属性行动/工具/serve.py
```

页面里改完，点「保存并更新导表」。服务只监听本机。

不想开页面时，直接改 `输入/属性行动.json`，再运行：

```bash
python3 docs/角色/属性行动/工具/build_workbook.py
```

双击打开 HTML 时读不到本机文件，也不能写回仓库。那种打开方式只能下载一份副本。

## 和原表的关系

原表「属性行动」里的加点、派生属性、S1 到 S5、秘籍类别，以及已经写了消耗和收益的行动，都保留着。补上的行动标了来源「补全」。

三处按原意改过位置，来源是「原表改写」：

- 「攻城」那一行里的山寨、匪窝条件，改记在「清剿山寨」。攻城只打城。
- 内政写了两次吏部，第二次改成礼部。队伍大于 10 人的门槛留给「账房」，六部要到占城、有吏员之后。
- 速度经验并入敏捷。基础属性里没有单独的速度。

同名的行动和技能不是一条数据。行动给经验或资源，技能是学会之后的常量。桩功、药浴、观摩、冥想都是这样。

兵役和国势的比例只在这套表里引用。正式数字仍以 `docs/country/行政区域/特征/` 为准。中原是天衡和昭武。
